# Unemployment Analysis with Python

## Project Overview
This project analyses unemployment rates in India using Python. It explores unemployment trends, investigates the impact of COVID-19, compares rural and urban unemployment, and identifies regional differences.

## Objectives
- Analyse unemployment rate data.
- Clean and prepare datasets using Python.
- Visualize unemployment trends.
- Investigate the impact of COVID-19.
- Compare rural and urban unemployment.
- Identify regional unemployment patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the analysis:

```bash
python unemployment_analysis.py
```

Ensure that `archive.zip` is in the project directory.

## Key Findings
- Unemployment increased significantly during COVID-19.
- Urban areas experienced higher average unemployment than rural areas.
- Regional unemployment rates varied considerably.
- Unemployment began declining after the initial lockdown period.
